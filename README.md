# ABAP Learning – CDS Views

This repository contains ABAP CDS view entities created in SAP BTP ABAP Environment
as part of my learning journey.

## Contents
- CDS view entities with inner joins
- Flight booking overview based on SAP DMO model
- Examples of annotations (@EndUserText, @Semantics, authorization handling)

## Technologies
- ABAP in Eclipse (ADT)
- ABAP CDS (View Entities)
- SAP BTP ABAP Environment

## Notes
- Objects are prefixed with Z*
- Demo model (/DMO/*) is used as data source
